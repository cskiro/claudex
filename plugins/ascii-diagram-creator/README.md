# ascii-diagram-creator

ASCII diagrams and text-based visual representations of systems, workflows, architecture, and relationships

## Installation

```bash
/plugin install ascii-diagram-creator@claudex
```

## Usage

This plugin provides the `ascii-diagram-creator` skill. Invoke it with:

```
/ascii-diagram-creator
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/ascii-diagram-creator/SKILL.md`](./skills/ascii-diagram-creator/SKILL.md) for detailed usage instructions.
