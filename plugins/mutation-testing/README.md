# mutation-testing

Test suite quality validation through mutation testing - finds weak tests and measures mutation score beyond coverage

## Installation

```bash
/plugin install mutation-testing@claudex
```

## Usage

This plugin provides the `mutation-testing` skill. Invoke it with:

```
/mutation-testing
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/mutation-testing/SKILL.md`](./skills/mutation-testing/SKILL.md) for detailed usage instructions.
