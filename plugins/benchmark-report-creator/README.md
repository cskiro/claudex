# benchmark-report-creator

Research reports, experiment writeups, technical whitepapers, and empirical study documentation for LLM benchmarking

## Installation

```bash
/plugin install benchmark-report-creator@claudex
```

## Usage

This plugin provides the `benchmark-report-creator` skill. Invoke it with:

```
/benchmark-report-creator
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/benchmark-report-creator/SKILL.md`](./skills/benchmark-report-creator/SKILL.md) for detailed usage instructions.
