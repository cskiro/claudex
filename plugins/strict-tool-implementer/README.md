# strict-tool-implementer

Anthropic API strict tool use implementation for guaranteed schema compliance and validated inputs

## Installation

```bash
/plugin install strict-tool-implementer@claudex
```

## Usage

This plugin provides the `strict-tool-implementer` skill. Invoke it with:

```
/strict-tool-implementer
```

Or reference it in conversation - Claude will activate it based on context.
