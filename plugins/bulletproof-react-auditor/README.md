# bulletproof-react-auditor

React project structure auditing using Bulletproof React patterns, anti-pattern detection, and feature-sliced architecture guidance

## Installation

```bash
/plugin install bulletproof-react-auditor@claudex
```

## Usage

This plugin provides the `bulletproof-react-auditor` skill. Invoke it with:

```
/bulletproof-react-auditor
```

Or reference it in conversation - Claude will activate it based on context.
