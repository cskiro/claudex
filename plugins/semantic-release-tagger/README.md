# semantic-release-tagger

Automated git tagging and release management using conventional commits and semantic versioning

## Installation

```bash
/plugin install semantic-release-tagger@claudex
```

## Usage

This plugin provides the `semantic-release-tagger` skill. Invoke it with:

```
/semantic-release-tagger
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/semantic-release-tagger/SKILL.md`](./skills/semantic-release-tagger/SKILL.md) for detailed usage instructions.
