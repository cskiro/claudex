# accessibility-audit

WCAG compliance auditing, screen reader testing, keyboard navigation validation, and color contrast analysis for React/TypeScript applications

## Installation

```bash
/plugin install accessibility-audit@claudex
```

## Usage

This plugin provides the `accessibility-audit` skill. Invoke it with:

```
/accessibility-audit
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/accessibility-audit/SKILL.md`](./skills/accessibility-audit/SKILL.md) for detailed usage instructions.
