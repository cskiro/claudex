# cc-insights

RAG-powered Claude Code conversation analysis, development pattern search, and activity report generation

## Installation

```bash
/plugin install cc-insights@claudex
```

## Usage

This plugin provides the `cc-insights` skill. Invoke it with:

```
/cc-insights
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/cc-insights/SKILL.md`](./skills/cc-insights/SKILL.md) for detailed usage instructions.
