# skill-creator

Claude Code skill generation following Claudex marketplace standards with templates, pattern detection, and quality validation

## Installation

```bash
/plugin install skill-creator@claudex
```

## Usage

This plugin provides the `skill-creator` skill. Invoke it with:

```
/skill-creator
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/skill-creator/SKILL.md`](./skills/skill-creator/SKILL.md) for detailed usage instructions.
