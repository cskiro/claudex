# claude-md-auditor

CLAUDE.md configuration validation against Anthropic documentation and community best practices

## Installation

```bash
/plugin install claude-md-auditor@claudex
```

## Usage

This plugin provides the `claude-md-auditor` skill. Invoke it with:

```
/claude-md-auditor
```

Or reference it in conversation - Claude will activate it based on context.
