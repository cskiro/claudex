# e2e-testing

End-to-end testing setup with Playwright, LLM-powered visual analysis, screenshot comparison, and browser automation

## Installation

```bash
/plugin install e2e-testing@claudex
```

## Usage

This plugin provides the `e2e-testing` skill. Invoke it with:

```
/e2e-testing
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/e2e-testing/SKILL.md`](./skills/e2e-testing/SKILL.md) for detailed usage instructions.
