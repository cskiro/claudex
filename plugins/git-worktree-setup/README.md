# git-worktree-setup

Git worktree automation for parallel branch development and multiple Claude Code sessions

## Installation

```bash
/plugin install git-worktree-setup@claudex
```

## Usage

This plugin provides the `git-worktree-setup` skill. Invoke it with:

```
/git-worktree-setup
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/git-worktree-setup/SKILL.md`](./skills/git-worktree-setup/SKILL.md) for detailed usage instructions.
