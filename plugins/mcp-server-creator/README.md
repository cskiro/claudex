# mcp-server-creator

Model Context Protocol server generation for connecting AI applications to external data sources, tools, and workflows

## Installation

```bash
/plugin install mcp-server-creator@claudex
```

## Usage

This plugin provides the `mcp-server-creator` skill. Invoke it with:

```
/mcp-server-creator
```

Or reference it in conversation - Claude will activate it based on context.
