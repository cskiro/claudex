# github-repo-setup

GitHub repository creation with best practices - quick public repos, enterprise-grade workflows, and project templates

## Installation

```bash
/plugin install github-repo-setup@claudex
```

## Usage

This plugin provides the `github-repo-setup` skill. Invoke it with:

```
/github-repo-setup
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/github-repo-setup/SKILL.md`](./skills/github-repo-setup/SKILL.md) for detailed usage instructions.
