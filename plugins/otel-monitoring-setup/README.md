# otel-monitoring-setup

OpenTelemetry monitoring setup for Claude Code usage tracking, cost analysis, and productivity metrics

## Installation

```bash
/plugin install otel-monitoring-setup@claudex
```

## Usage

This plugin provides the `otel-monitoring-setup` skill. Invoke it with:

```
/otel-monitoring-setup
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/otel-monitoring-setup/SKILL.md`](./skills/otel-monitoring-setup/SKILL.md) for detailed usage instructions.
