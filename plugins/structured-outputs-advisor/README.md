# structured-outputs-advisor

Expert advisor for Anthropic structured outputs - choosing between JSON outputs and strict tool use

## Installation

```bash
/plugin install structured-outputs-advisor@claudex
```

## Usage

This plugin provides the `structured-outputs-advisor` skill. Invoke it with:

```
/structured-outputs-advisor
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/structured-outputs-advisor/SKILL.md`](./skills/structured-outputs-advisor/SKILL.md) for detailed usage instructions.
