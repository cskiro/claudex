# react-project-scaffolder

React project scaffolding with modern tooling - sandbox mode (Vite), enterprise mode (Next.js with testing and CI/CD)

## Installation

```bash
/plugin install react-project-scaffolder@claudex
```

## Usage

This plugin provides the `react-project-scaffolder` skill. Invoke it with:

```
/react-project-scaffolder
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/react-project-scaffolder/SKILL.md`](./skills/react-project-scaffolder/SKILL.md) for detailed usage instructions.
