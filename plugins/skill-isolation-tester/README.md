# skill-isolation-tester

Skill validation in isolation environments (git worktree, Docker, VMs) before public release

## Installation

```bash
/plugin install skill-isolation-tester@claudex
```

## Usage

This plugin provides the `skill-isolation-tester` skill. Invoke it with:

```
/skill-isolation-tester
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/skill-isolation-tester/SKILL.md`](./skills/skill-isolation-tester/SKILL.md) for detailed usage instructions.
