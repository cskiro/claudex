# insight-skill-generator

Transforms Claude Code explanatory insights from docs/lessons-learned/ into reusable, production-ready skills

## Installation

```bash
/plugin install insight-skill-generator@claudex
```

## Usage

This plugin provides the `insight-skill-generator` skill. Invoke it with:

```
/insight-skill-generator
```

Or reference it in conversation - Claude will activate it based on context.

## Skill Documentation

See [`skills/insight-skill-generator/SKILL.md`](./skills/insight-skill-generator/SKILL.md) for detailed usage instructions.
