# codebase-auditor

Code quality auditing, security scans, technical debt assessment, production readiness review, and DORA metrics tracking

## Installation

```bash
/plugin install codebase-auditor@claudex
```

## Usage

This plugin provides the `codebase-auditor` skill. Invoke it with:

```
/codebase-auditor
```

Or reference it in conversation - Claude will activate it based on context.

See [`skills/codebase-auditor/SKILL.md`](./skills/codebase-auditor/SKILL.md) for detailed usage instructions.
