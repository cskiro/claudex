# sub-agent-creator

Specialized Claude Code sub-agent creation following Anthropic patterns with proper tool configuration

## Installation

```bash
/plugin install sub-agent-creator@claudex
```

## Usage

This plugin provides the `sub-agent-creator` skill. Invoke it with:

```
/sub-agent-creator
```

Or reference it in conversation - Claude will activate it based on context.
